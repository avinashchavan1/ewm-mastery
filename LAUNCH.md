## 5. Google Search Console (do this first — it's how you get indexed fast)

1. Go to https://search.google.com/search-console → **Add property** → URL prefix `https://ewm.avinashchavan.com`.
2. Verify. Easiest here: **HTML tag** method → it gives a `<meta name="google-site-verification" content="TOKEN">`. Paste that TOKEN to me and I'll bake it into the site. (Or use DNS TXT via your domain registrar — also fine.)
3. After verifying → **Sitemaps** → submit `sitemap.xml`.
4. Use **URL Inspection** → "Request indexing" on the homepage and a couple of key pages.
5. Repeat add-property + sitemap on **Bing Webmaster Tools** (https://www.bing.com/webmasters) — you can import from GSC in one click.

Then check **Rich Results Test** (https://search.google.com/test/rich-results) on an incident URL
and a day URL — the FAQ/Article structured data should validate.
